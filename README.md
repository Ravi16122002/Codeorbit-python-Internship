# Simple Calculator

# Project Overview

This project is a simple calculator developed using Python as part of the CodeOrbit Tech Python Programming Internship.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Handles invalid numeric input
* Prevents division by zero
* Handles invalid operators

## Technologies Used

* Python 3
* Visual Studio Code

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python calculator.py
```

* Python variables and data types
* User input and output
* Conditional statements
* Exception handling
* Basic arithmetic operations
