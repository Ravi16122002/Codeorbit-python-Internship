# 🐍 CodeOrbit Tech — Python Programming Internship

## 📌 About the Repository

This repository contains three Python projects developed as part of the **CodeOrbit Tech Python Programming Internship**. These projects demonstrate fundamental Python programming concepts, logical thinking, problem-solving, and practical application development.

## 🚀 Projects

### 1. Simple Calculator

A command-line calculator that performs basic mathematical operations.

**Features:**

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Handles invalid numeric inputs
* Prevents division by zero
* Handles invalid operators

**File:** `calculator.py`

**Run the project:**

```bash
python calculator.py
```

### 2. Number Guessing Game

An interactive game in which the computer generates a random number between 1 and 100, and the user attempts to guess it.

**Features:**

* Random number generation
* Hints when the guess is too high or too low
* Counts valid guessing attempts
* Handles invalid inputs
* Validates that guesses are between 1 and 100
* Displays a congratulatory message when the number is guessed correctly

**File:** `guessing_game.py`

**Run the project:**

```bash
python guessing_game.py
```

### 3. To-Do List CLI Application

A command-line task management application that allows users to manage their daily tasks.

**Features:**

* Add new tasks
* View all tasks with numbers
* Remove tasks by their numbers
* Save tasks in a text file
* Load previously saved tasks when the program starts
* Handle invalid menu choices and task numbers
* Organize the program using functions

**Files:**

* `todo_list.py` — Main Python application
* `tasks.txt` — Created automatically when tasks are saved

**Run the project:**

```bash
python todo_list.py
```

## 📥 Installation and Setup

### Prerequisites

* Python 3 installed on your computer
* Visual Studio Code or another Python-compatible editor
* GitHub account to access the source code

### Steps to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal in the project folder.
4. Run the Python file for the project you want to use.

For example:

```bash
python calculator.py
```

On Windows, if the `python` command does not work, try:

```bash
py calculator.py
```

You can similarly run `guessing_game.py` or `todo_list.py`.
